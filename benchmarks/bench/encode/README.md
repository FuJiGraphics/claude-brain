# 저장 벤치 (encode) - 사전 등록

이 폴더의 시나리오, 시작 기억 저장소, 채점 기준은 저장 개선 코드를 쓰기 전에 정해 커밋한 것이다(출제자 편향 방지).

흐름: 배우는 세션(sonnet, 새 brain 의 훅과 범례, 시작 기억 저장소) → 그 대화록 하나를 모든 갈래에 넣는다 → 갈래마다 그 갈래 코드의
재생 요약과 해마 지침으로 해마가 기억을 쓴다 → 기계 채점 → 시험 세션(새 복제본, 같은 상황, 결정은 말하지 않는다).

- 시나리오: `scenarios/*.json`. `learn` 은 배우는 세션(과제 글, 시작 상태), `key` 는 저장됐다고 볼 정규식(모두 한 기억 파일 안에 있어야 한다),
  `probe` 는 닿음 2차 지표용 상황(명령 출력 또는 편집), `test_task` 는 시험 세션 과제(`../tasks/*.json`, 채점은 `../checks/`).
- 시작 기억 저장소: `start-cortex.json` - 떠올림 벤치 픽스처에서 핵심 기억 둘을 뺀 것.
- 갈래: 기억 없음, 옛 저장(234a390 의 replay.py, hippocampus.md), 새 저장, 새 저장에서 세션 표시(M) 줄만 뺀 것(medium 이상), 이상적 기록(빼지 않은 픽스처).
- 채점: 저장됨(key 정규식), 닿음(1차 시험 세션의 recall.log 에 그 기억이 떠오르거나 열림, 2차 probe 로 훅과 검색을 돌린 결과), 쓰임(시험 세션 통과),
  잡음(noise 시나리오와 전체에서 새로 생긴 기억 수).
- 해마 모델 haiku, sonnet, opus 각 2회. 시험 세션은 low 에서 sonnet, medium 부터 세 모델.
