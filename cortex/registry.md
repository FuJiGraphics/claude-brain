# registry - 경로 프리픽스와 프로젝트의 매핑

cwd(또는 그 상위 경로)가 아래 프리픽스와 일치하면 그 프로젝트다. thalamus 는 여기 등록된 프로젝트 안에서만 기억을 떠올린다.
일치가 없으면 미등록 프로젝트라 아무것도 떠올리지 않는다. 등록은 hippocampus 가 한다(밤 주기가 자주 일하는 git 폴더를 자동으로 넘긴다).

| 경로 프리픽스 | 프로젝트 슬러그 | 스택 | 스택 버전 | 비고 |
|---|---|---|---|---|

- 세션이 시작되면 thalamus 가 그 프로젝트의 `projects/<슬러그>/INDEX.md` 를 보여 주고, 떠올림과 검색은 `projects/<슬러그>/`, `stacks/<스택>/`, `common/` 3레이어를 본다. 전부 얇은 인덱스만 읽고, 본문은 걸릴 때만 펼친다.
- 비고는 세션 시작 때 프로젝트 요지로 보인다(500자까지). 정체와 포인터 한두 문장으로 쓴다.
- 스택 버전은 lesson/단계 카드의 버전 태그 필터에 쓴다. 프로젝트가 엔진을 올리면 이 표의 버전만 갱신한다. 버전이 브랜치마다 다르면 이 칸에 브랜치별로 병기한다 - 한 값만 적으면 다른 브랜치에서 작업하는 세션이 그 값을 현행으로 읽고 없는 문제를 조사한다.
- 스택이 없는 프로젝트(순수 라이브러리 등)는 스택 칸을 `-` 로 두고 스택 레이어 검색을 생략한다.
