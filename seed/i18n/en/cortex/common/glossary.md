# glossary (agreed terms for this memory store)

These are the agreed words of this memory store. Tidy-ups use this table to fix old wording, and new lines follow it. Do not change words that are not in the table. Do not coin new terms; use plain, standard words, because invented terms make searches miss. `common/search-aliases.md` keeps old names searchable.

## 0. Rules

1. Replace only uses that match the condition in the table. If both meanings are possible, or you are unsure, leave it.
2. Never replace inside backticks, links, quotes, identifiers or slugs.
3. When you replace an old word in an index line, check that search-aliases.md has the pair. If it does not, add one line so the old word still finds the memory.
