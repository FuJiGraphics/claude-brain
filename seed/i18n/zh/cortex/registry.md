# registry - 路径前缀与项目的对应

工作文件夹(或它的上级)与下面某个前缀一致,就属于那个项目。thalamus 只在这里登记过的项目中回忆记忆。
没有匹配就是未登记的文件夹,什么都不会回忆。登记由 hippocampus 负责:夜间整理会把常用的 git 文件夹交给它,也可以用 /claude-brain-register 立即登记。

| 路径前缀 | 项目标识 | 技术栈 | 技术栈版本 | 备注 |
|---|---|---|---|---|

- 会话开始时 thalamus 会展示该项目的 `projects/<标识>/INDEX.md`。回忆和搜索查看 `projects/<标识>/`、`stacks/<技术栈>/` 和 `common/`,只读轻量的索引,匹配时才打开记忆文件。
- 备注会在会话开始时作为项目要点显示(最多 500 字)。用一两句话写清楚这是什么项目、该看哪里。
- 技术栈版本用于按版本标签筛选经验和步骤卡。项目升级引擎时只更新这一列。不同分支版本不同时,在这里按分支分别写。
- 没有技术栈的项目(纯库等)在技术栈一列写 `-`,跳过技术栈层。
