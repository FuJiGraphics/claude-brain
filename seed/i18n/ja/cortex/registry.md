# registry - パスの接頭辞とプロジェクトの対応

作業フォルダ(またはその親)が下の接頭辞に当てはまれば、そのプロジェクトです。thalamus はここに登録されたプロジェクトの中でだけ記憶を思い出します。
当てはまらなければ未登録のフォルダなので、何も思い出しません。登録は hippocampus が行います。夜の整理がよく作業する git フォルダを渡し、/claude-brain-register ですぐに頼むこともできます。

| パスの接頭辞 | プロジェクトのスラッグ | スタック | スタックのバージョン | メモ |
|---|---|---|---|---|

- セッション開始時に thalamus がそのプロジェクトの `projects/<スラッグ>/INDEX.md` を見せます。想起と検索は `projects/<スラッグ>/`、`stacks/<スタック>/`、`common/` を対象にし、薄い索引だけを読んで、当てはまったときだけ記憶ファイルを開きます。
- メモはセッション開始時にプロジェクトの要旨として表示されます(500 文字まで)。何のプロジェクトか、どこを見ればよいかを 1〜2 文で書きます。
- スタックのバージョンは教訓や手順カードのバージョンタグの絞り込みに使います。エンジンを上げたらこの列だけ更新します。ブランチごとにバージョンが違う場合は、ここにブランチ別に書きます。
- スタックのないプロジェクト(純粋なライブラリなど)はスタックの列を `-` にし、スタックの層を飛ばします。
