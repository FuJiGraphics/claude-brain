# 検索の別名

検索エンジン(自動の想起と recall.sh)が検索語を広げるのに使います。検索語全体が行の要素の 1 つと一致すると、同じ行のほかの要素も一緒に探します。セッションがこのファイルを読むことはありません。
1 行に 1 グループ、`- 言葉1 = 言葉2 = 言葉3`、すべて同じ意味です。古い名前を新しい名前に変えたときや、同じものに名前が複数あるときに 1 行足します。ごく短いありふれた言葉や一般的な英単語は入れません(検索語が爆発的に広がります)。

- notebook = cortex = 記憶の保存先
- curator = hippocampus = 海馬
- nb-grep = recall.sh = recall
