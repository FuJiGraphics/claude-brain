# 用語集(この記憶の保存先で決めた用語)

この記憶の保存先で決めた言葉です。整理のときに古い言い方を直す基準になり、新しく書く行もこれに従います。表にない言葉は変えません。新しい造語は作らず、ふつうの言葉で書きます。造語は検索語が合わなくなる原因になります。古い名前でも見つかるように `common/search-aliases.md` がつないでいます。

## 0. 規則

1. 表の条件に合う使い方だけを置き換えます。どちらの意味にも取れるとき、確信がないときはそのままにします。
2. バッククォート、リンク、引用、識別子、スラッグの中は置き換えません。
3. 索引の行で古い言葉を置き換えたら、search-aliases.md にその組があるか確かめ、なければ 1 行足して古い言葉でも見つかるようにします。

## 1. 用語

| # | 古い言葉 | 条件 → 新しい言葉 |
|---|---|---|
| 1 | notebook、ノート | 記憶の保存先全体 → cortex(文章では「記憶の保存先」) |
| 2 | curator | バックグラウンドで書く担い手 → hippocampus(海馬) |
| 3 | nb-grep | 検索コマンド → recall.sh |
| 4 | メモ、項目 | lessons/ の下の記憶ファイル 1 つ → 教訓(lesson) |
| 5 | 索引項目、リンク行 | 最初のリンクが記憶ファイルである行 → 索引の行 |
| 6 | 隠した記憶 | forget.py が dormant.md に移した索引の行 → 眠っている記憶 |
| 7 | 削除 | _archive/ に移した記憶 → アーカイブ(完全には削除しない) |
