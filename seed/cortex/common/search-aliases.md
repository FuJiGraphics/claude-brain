# 검색 별칭

검색 엔진(thalamus 의 자동 떠올림과 recall.sh)이 질의 확장에 쓴다. 질의 전체가 한 구성원과 같으면 같은 줄의 나머지 구성원도 함께 찾는다. 읽는 쪽은 검색 엔진이라 세션이 직접 읽을 일은 없다.
한 줄 한 그룹 `- 말1 = 말2 = 말3`, 한 그룹은 모두 같은 뜻이다. 옛말을 새말로 바꿨거나 같은 뜻의 말이 여럿일 때 한 줄 더한다. 흔한 한 글자,두 글자 말과 범용 영문은 넣지 않는다(질의 확장이 폭주한다).

- 노트북 = cortex = 기억 저장소
- curator = hippocampus = 해마
- nb-grep = recall.sh = recall
