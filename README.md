# brain media

이 브랜치는 README 에 싣는 홍보 영상, 미리보기, 스크린샷만 담습니다. 스킬 코드는 `main` 에 있습니다.
영상은 `promo/make_promo.sh <ko|en|ja|zh>`, 스크린샷은 `promo/make_shots.sh <ko|en|ja|zh>` 로 다시 만듭니다(가상의 데모 뇌로 찍습니다).

This branch only holds the promo videos, previews and screenshots used by the READMEs. The skill lives on `main`.
Videos are rebuilt with `promo/make_promo.sh <ko|en|ja|zh>` and screenshots with `promo/make_shots.sh <ko|en|ja|zh>` (recorded on a made-up demo brain).
